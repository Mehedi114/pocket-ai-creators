A PRACTICAL EXAMPLE

Put it to work

From a ten-page report, choose 1, 8-10 to create a file with the introduction and closing section. Repeated page numbers are included only once.

Important limits

This extracts one file per run, not a ZIP containing one file for every page. Repeat with another selection to create multiple parts. Limits include 20 MB and 500 pages; document features may not survive rewriting.

Common questions

Are page numbers zero-based?

No. Enter 1 for the first page. The tool validates ranges against the document's actual page count and rejects descending or out-of-range selections.
