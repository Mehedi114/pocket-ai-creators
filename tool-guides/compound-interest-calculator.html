A PRACTICAL EXAMPLE

Put it to work

At a zero return, an initial 1,000 plus twelve monthly contributions of 100 produces 2,200. A positive assumed return adds growth through monthly compounding.

Important limits

Contributions are added at the end of each month. The model excludes taxes, fees, inflation, volatility and withdrawals. Returns are hypothetical rather than forecasts or guarantees.

Common questions

When are the monthly deposits invested?

At each month end in this model. Beginning-of-month contributions would have more time to earn returns and can produce a different result.

What should I check before using the result?
