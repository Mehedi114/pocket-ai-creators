A PRACTICAL EXAMPLE

Put it to work

An email campaign can use source=newsletter, medium=email and campaign=summer_launch. Use content=hero_button to distinguish a header button from a footer link in the same message.

Important limits

UTM links are longer tracking URLs, not shortened links. The tool does not collect analytics itself. Existing non-UTM parameters and URL fragments are preserved; blank optional UTM fields remove those parameters.

Common questions

Will this shorten my website link?

No. This is a campaign URL builder, not a shortener. It adds tracking parameters. Attribution only works if the destination's analytics software records and interprets them.
