Important limits

This workflow supports UTF-8 text, not arbitrary binary files. Decoding expects valid padded Base64 and rejects invalid UTF-8. Base64 provides no confidentiality.

Common questions

Can I protect a password with Base64?

No. Anyone can reverse Base64 without a secret key. Use established encryption and a password manager instead of treating encoding as security.
